# X500

The X500 is the [[Quadrotor]] [[PX4 Autopilot|PX4]] uses as its default vehicle in [[Gazebo]]. The number is a size class: on the order of 500 millimetres between opposite motors. Holybro sells a developer frame of that class. The simulated model is the one you get when you start this repo's simulator and do not name another vehicle.

## The problem

A controller tuned on a made-up mass will not match a real airframe, and a mixer written for a different motor order will flip the aircraft on the first arm. A named default vehicle means the mass, the inertia, the motors, and the sensor poses are a shared contract.

## In this playground

This repo does not load the X500. [[Simulation]] uses the X3 mass and rotor positions. The X500 is the vehicle you meet in [[PX4 Autopilot]] examples. Changing mass or motor constants in the SDF is how you see whether a loop still holds on a slightly different aircraft.
